# Gestor de Incidencias

Aplicación web desarrollada en Java con Jakarta Servlets y MySQL para la gestión de incidencias. Permite a los usuarios autenticarse, crear incidencias y consultar su estado, mientras que los administradores pueden gestionar y modificar su evolución.

---

## Tecnologías utilizadas

- Java 17+
- Jakarta Servlets (Tomcat 10+)
- MySQL
- JDBC
- Maven
- HTML y JSP

---

## Requisitos

Para ejecutar el proyecto es necesario disponer de:

- JDK 17 o superior
- Apache Tomcat 10+
- MySQL Server
- Maven
- Entorno de desarrollo compatible (Eclipse, IntelliJ o similar)
